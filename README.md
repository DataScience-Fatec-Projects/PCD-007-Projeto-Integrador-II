# PCD-007-Projeto-Integrador-II
Instalação e config de amb de prog e o de operação (R). Desenvolvimento de softwares mais complexos que envolvam: extração de dados, filtragem, cálculos estatísticos e visualização de dados de forma gráfica. Aplicação dos conceitos aprendidos nos componentes curriculares do semestre em bases de dados públicas ou disponibilizadas por empresas.
